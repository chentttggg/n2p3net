## 主结果

普通四库留出中，K=200 的平均 AUC 如下：

| 处理 | 平均 AUC |
|---|---:|
| A0Q0：CE 源 + 普通 full-fine | 0.6995 |
| A1Q1：CE+SupCon+MMD 源 + prior/decision 适配 | 0.6895 |
| A0Q1：CE 源 + prior/decision 适配 | 0.6971 |
| A1Q0：增强源 + 普通适配 | 0.7003 |
| CE scratch | 0.6581 |
| decision scratch | 0.6551 |
| 波形 LDA | 0.6925 |

统一 A1Q1 相对普通 A0Q0 的 participant macro 差为 **-0.0100**，95% bootstrap 区间 `[-0.0220, 0.0014]`，Holm 校正后 `p=0.1611`。因此普通四库上没有证据证明完整联合包优于普通 full-fine。K=800 时差为 **-0.0159**，区间 `[-0.0223, -0.0095]`，说明高校准预算下完整包反而更差。

迁移本身仍明显有效：A1Q1 相对 decision scratch 在 K=200 提高 **0.0344**，区间 `[0.0231, 0.0458]`，Holm 校正后 `p<0.0001`；A0Q0 相对 CE-only scratch 提高 **0.0414**。因此主要收益来自 source 初始化/共享表征，来自 Q1 的 prior/decision 机制没有带来额外整体收益。

源端增强包的独立贡献很小：A1Q0−A0Q0 在 K=200 为 **+0.0008**，区间 `[-0.0058, 0.0075]`；在 Q1 下 A1Q1−A0Q1 为 **-0.0076**，区间 `[-0.0142, -0.0006]`。A×Q interaction 为 **-0.0084**，区间 `[-0.0123, -0.0046]`，提示增强源目标与 Q1 目标适配存在负交互。

波形 LDA 与完整联合包接近：A1Q1−LDA 在 K=200 为 **-0.0031**，区间 `[-0.0153, 0.0085]`；当前证据不足以宣称神经统一包超过 LDA。

## BI 敏感性

BI 相关联合排除只评价 BI2014a 和 BI2015a。K=200 时 A1Q1−A0Q0 为 **-0.0166**，区间 `[-0.0236, -0.0096]`，Holm 校正后 `p=0.00016`；A1Q1−scratch 为 **+0.0258**，区间 `[0.0151, 0.0365]`。这说明迁移相对 scratch 仍有效，但完整联合机制在 BI 家族内明显落后于普通 full-fine，负效应主要由 BI2015a 驱动（该库差为 -0.0327，95% 区间 `[-0.0413,-0.0244]`）。K=800 时 A1Q1−A0Q0 为 +0.0044，区间跨 0，不能把 K=200 的负效应外推到所有预算。

## BNCI 决策监督（hit@all）

BNCI2014-008 是本轮实际有 membership decision supervision 的目标库。每个 BNCI 物理 decision 都恰好有 10 次原生重复，因此使用全部重复的 `hit@all` 等于已保存的 R=10 聚合；不再把 R=5 作为主标准。结果为：

| 处理 | K=200 hit | K=800 hit |
|---|---:|---:|
| A0Q0 | 0.457 | 0.716 |
| A1Q0 | 0.422 | 0.720 |
| A0Q1 | 0.362 | 0.565 |
| A1Q1 | 0.276 | 0.509 |
| CE scratch | 0.388 | 0.586 |
| decision scratch | 0.341 | 0.500 |
| LDA | 0.422 | 0.746 |

## 结论和后续决策

1. **保留统一程序和固定 recipe 枚举。** 结果支持 source 初始化迁移优于 scratch，但不支持完整 A1Q1 取代普通 A0Q0。
2. **默认研究基线应是 A0Q0/full-fine。** A1 源辅助目标的独立收益接近零，和 Q1 组合时出现负交互。
3. **Q1 prior/decision 不能晋升默认。** BNCI 的真实 membership 监督结果下降，且普通四库整体也没有收益。
4. **CE-only scratch 对照是必要的。** 它将初始化差异与 decision supervision 差异分开，避免把两个因素混成“full vs scratch”。
5. **LDA 仍是有竞争力的低复杂度对照。** 神经联合包没有稳定超过 LDA；下一步应优先做预注册的机制缩减或多 seed 复核，而不是按被试结果切换模块。

这些结论只覆盖本轮冻结输入、双向预处理、单 seed 和公共开发目标。部署源模型仅用于完整十二库部署，不继承上述留出评价含义。
