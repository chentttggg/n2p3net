# BI 家族（BrainInvaders 2012–2015b）跨域迁移普查

日期：2026-09-04 | 触发：T 明确「我要测 BI 集之间的迁移」
方法：只读普查（本地 `mne_data/MNE-braininvaders*-data/`，通道定义取自 moabb 1.6.1 权威加载器 `moabb/datasets/braininvaders.py` L74–170）
结论：**BI 家族内部迁移可行，且严格优于此前推荐的 GTN 路线**

---

## 1. 六数据集总览（moabb 官方 docstring）

| 数据集 | 被试 | 通道 | 采样 | 电极 | 实验设计要点 |
|---|---|---|---|---|---|
| BI2012 | 25 | 17（16+stim） | **128 Hz** | — | 2012 GIPSA；含 training + online 两种 run |
| BI2013a | **24** | 16 | 512 Hz | — | **1–7 号被试各 8 个 session（不同天）**，8–24 号各 1 个；每 session 含 Non-Adaptive / Adaptive 两 run |
| **BI2014a** | **71**（现有 cache 64） | 16 | 512 Hz | **有源干电极** | 6×6 grid，**最多 3 个 game session** ← 当前全部实验的基础 |
| BI2014b | 38（19 对） | **32 湿电极**（双人共 64） | 512 Hz | 湿 | 三条件：Solo1 / Solo2 / **Collaboration** |
| BI2015a | 43 | **32 湿电极** | 512 Hz | 湿 | 三条件：**flash 时长 50 / 80 / 110 ms** |
| BI2015b | 44（22 对） | **32 湿电极**（双人共 64） | 512 Hz | 湿 | 四条件：Coop-1T / Coop-2T / Compete-1T / Compete-2T |

**全部是同一范式**：6×6 = 36 symbols（1 target + 35 non-target），oddball，伪随机闪烁。
⇒ **任务语义完全一致（row_column），不需要任何 direct 语义支持** —— 这是对比 GTN 路线的最大成本节省。

## 3. 现成的域定义（不需要人为切分）

| 域轴 | 数据集 | 域语义 |
|---|---|---|
| **电极类型** | 2014a（干）× 2014b/2015a/2015b（湿） | 硬件域漂移 —— **与 T 的目标硬件（干电极）直接相关** |
| **年份 / 采集批次** | 任意跨年配对 | 批次漂移 |
| **session（不同天）** | **BI2013a**（1–7 号各 8 天）、BI2014a（≤3 session） | **multi-session 漂移 —— BrainSync 产品线的直接代理** |
| **刺激参数** | BI2015a（flash 50/80/110 ms） | 刺激时长域 |
| **任务模式** | BI2014b（Solo / Collaboration）、BI2015b（Coop / Compete） | 认知状态域 |
| **自适应模式** | BI2013a（Non-Adaptive / Adaptive run） | 算法-被试交互域 |

**与 P0/P1 的匹配度**：P0 Split-BN 的设计前提正是「同任务、同标签空间、特征空间内分布漂移」。BI 家族配对**完全满足**，且漂移来源可命名（干/湿、年份、session、刺激参数）——失败时可归因，不像 BI×GTN 那样三重失配缠在一起。

## 4. 与 GTN 路线的对比（推荐度反转）

| 维度 | BI 家族内迁移 | GTN 路线 |
|---|---|---|
| 任务语义 | row_column，**一致** | 9 选 1 direct，**需 direct 语义支持（框架硬门现只认 row_column）** |
| 通道交集 | **12–32 导**（CAR 安全） | **2 导**（CAR 摧毁 P300，已实测） |
| 参考 | 需按集核对 | 右耳垂 vs 鼻尖，已不同 |
| 数据可得性 | **已在本地 `mne_data/`** | 已在本地，但需 L0 构建 |
| 域语义 | 电极类型 / 年份 / session / 刺激参数 —— 可命名、可归因 | 仅"跨被试群"，需人为切分 |
| 与产品线对齐 | 干电极 → 8 导干电极（部分对齐） | 9 选 1 语义对齐，但 3 导 ⊂ 8 导 |

**结论：BI 家族内迁移严格占优**（语义零改动 + 通道安全 + 域可归因）。GTN 路线的唯一优势（9 选 1 语义与产品线一致）在"先验证域适应机制"这个目标面前是次要的。

## 5. 两个必须先解决的前置（否则方案有洞）

### 5.1 hit@R 的证据深度（target 侧决定，换 source 救不了）

现有 BI2014a 的 rep 结构：1–8 轮参差，**仅 5.2% 的 test selection 达到 8 层** → hit@R=8 结构性归零。
**换 source 数据集不解决这个问题**——eligibility 取决于 target 的 rep 深度。

两条出路：
1. **降 R**（T 已申明 @8 不是规范，只是随口指标）：BI2014a 在 R=2 时 **68.1%** 的 selection eligible；R=3 时 44%。
2. **普查其他数据集的 rep 结构**：若 BI2015a/2015b 是固定 rep（如 BNCI2014-008 的 10 轮固定），则选它们作 target 可恢复深 R。

⇒ **下一步第一件事：对 6 个数据集做 rep 深度普查**（CSV 类 2012/2013a/2014a 可直接读事件列；MAT 类 2014b/2015a/2015b 需解压后读事件列，成本较高但只需抽样少数被试）。

### 5.2 被试身份重叠（泄漏风险）

BI2014a（71 人）与 BI2014b（38 人 = 19 对）**同年同实验室**，是否同一批被试群未知。若重叠，"迁移"实为泄漏。

风险排序与规避：
- **跨年配对（2014a × 2015a/2015b）重叠风险最低** —— 推荐优先
- 同年配对（2014a × 2014b）需显式核对被试身份（年龄/性别/采集日期元数据）
- 框架侧有 `identity_exclusion_policy` 与 `source_or_global` 排他策略可兜底

## 6. 推荐的第一轮设计（待 T 拍板）

| 项 | 建议值 | 理由 |
|---|---|---|
| source 域 | **BI2015a（43 人，32 导湿电极）** 或 BI2015b（44 人） | 跨年、被试量大、与 2014a 通道交集 16（零损失） |
| target 域 | **BI2014a（64 人，16 导干电极）** | 已有 causal cache，**干电极与目标硬件同类型** |
| 通道对齐 | 16 导公共子集（2014a ⊂ 32 导，无损） + 统一 CAR | 契约现成（`domain.py`） |
| 域语义 | 干/湿电极 × 年份（2014 vs 2015） | 可命名、可归因 |
| 对照臂 | ① pooled-BN ↔ P0 Split-BN；② P1 off ↔ on；③ zero_shot ↔ target_adapter | P0/P1 首次获得真域，可真正启用 |
| R | 按 §5.1 普查结果定（BI2014a 侧建议先试 R=2） | @8 非规范 |
| L0 工作 | 需为 source 数据集新建 causal cache（构建器模式可复用 `bi2014a_candidate.py`，需适配 MAT + 32 导） | 主要工程量 |
