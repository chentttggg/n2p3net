# BI2014a 128 Hz Head Ablation - 2026-08-28

Status: immutable historical comparison of four heads. Its decisions apply only
to this BI2014a binary candidate set. A later preregistered run found linear
`full_unfold` mean AUC `0.745109`; GTN 9-choice can only serve as a development
benchmark because that cohort has already been inspected repeatedly. Final product
confirmation requires new target-switch decisions from adult BrainSync sessions.

## Protocol

Run: `bi2014a_128_contract_head_ablation_20260828_r1`

- Dataset: BI2014a, 64 subjects, 61,015 held-out trials in total.
- Input: 128 Hz, 2--30 Hz, `[-200,800) ms`, mean-only baseline, volts.
- Evaluation: 64-fold LOSO; group-disjoint validation/calibration.
- Training: seed 20260828, BF16, batch 512, at most 30 epochs.
- Runtime: RTX 5090 32 GB, four isolated fold workers.
- QC: one set of 64 fold-local policies, frozen and reused by every model.
- Cache SHA-256:
  `60f7c97fce94dc808784972f5acbfc326f7e1de4af61353c25e94eaa7e672d4b`.

## Decisions

1. EEGNet was the mean leader in this dated BI protocol; there is no current overall champion.
2. Linear `full_unfold` is the adopted N2P3-Net readout; MS-EEGNet/`ms_flatten`
   remains an explicit baseline. This dated BI comparison does not make either a
   product-accuracy champion.
3. LMBC failed its promotion criterion. It remains only as
   `n2p3net_lmbc` for preregistered countertests.
4. Global average confirms the temporal-position-loss counterexample and is
   retained only as a negative control.

These are single-dataset, single-seed conclusions. Cross-dataset confirmation,
decision-level candidate metadata, and batch-1/deployed-batch latency profiling
remain required before final deployment promotion.
