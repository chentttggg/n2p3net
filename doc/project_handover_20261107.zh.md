## 一、接任负责人首先需要掌握的判断

项目的最终目标是：利用成人本人少量已知目标的脑电记录进行校准，再从后续独立记录中，识别其心中选择的 1—9 数字。公开 P300 数据是训练和研究材料；最终验收对象是 BrainSync 成人九选一任务。[S02]

目前已经具备公开数据接入、神经网络预训练、本人校准、个人模型保存加载、独立记录推理和 BrainSync 应用调用的完整软件链。项目也积累了较大规模公共数据实验、单人真实记录的回顾性比较，以及连续响应、噪声和人群先验的研究实现。接任时最需要补齐的是输入处理稳定性、原始实验产物可恢复性，以及冻结程序后的独立成人评价。

以下五点决定接手后的工作顺序：

1. **把历史成绩放回其原任务中。** 旧 basic 的 98.33% 来自一名参与者、两份固定测试录制、20 个物理 block，以及三个目标训练 seed 的平均；每个 block 累计 45 次闪烁。同条件单轮九选一是 48.67%。这两项衡量的证据量不同。[E01、B01、B02]
2. **优先处理眼电回归稳定性。** 启动裁剪后的 C1 QC/EOG 包在固定测试上产生 228 个超过 1 mV 的保留 epoch；保相同 mask 和滤波、只撤销 EOG 扣除后，该计数变为 0。当前有明确的处理放大问题。[E02、B05]
3. **完成输入更改后的新比较。** 11 月新增的启动裁剪改变原始支持，旧矩阵分数保留原效力；需要在新支持上重新拟合、训练和评价。新 basic/QC 神经链的完整结果尚未取得可核验的完成凭证。[E01、B04、B06]
4. **先找回详细产物，再续接大型研究。** 当前 `experiments/runs/` 不在原路径。此次抽查三份接受绑定中的 30 个详细产物引用，29 个原路径不存在；小型接受记录、部分原始数据和其他研究交付目录仍在。现有材料足以解释已有结论，尚不足以在本机完整重放这些矩阵。[L01]
5. **独立成人确认仍是最终出口。** 单人的多 block、多个 seed，以及公共 32/36 选一结果，各自提供开发证据；它们没有增加独立成人参与者。

## 二、任务是什么：先把实验单位讲清楚

### 2.1 从一次闪烁到一次猜数字

被试先心选一个数字。屏幕依次呈现数字；当呈现心选数字时，这次刺激标作 **target（目标刺激）**，其余刺激标作 **non-target（非目标刺激）**。算法利用两类事件相关脑电的差异积累证据。

| 名称 | 本项目中的含义 | 例子 |
|---|---|---|
| flash / trial，闪烁 / 刺激试次 | 一次刺激事件及其对应观测 | 数字 7 闪烁一次 |
| EEG epoch，脑电切片 | 围绕一个刺激截取的波形窗口 | 刺激前 200 ms 到刺激后 1200 ms |
| training epoch，训练轮 | 优化器遍历训练数据的一轮 | 个人模型训练 90 轮；这里的 epoch 与脑电切片不同 |
| repetition / round，重复 / 轮 | 对九选一直接呈现任务，九个数字各闪一次 | 共 9 次 flash，记 R1 |
| block，块 | 本人实验中五轮九数字刺激 | 45 次 flash，通常相当于 R5 |
| decision / selection，一次判定 | 程序要给出一个候选答案的任务单位 | 从该 block 的证据中输出数字 7 |
| recording / session，录制 / 会话 | 一份独立采集记录，可能包含多个 block | 一份 450 闪烁记录通常含 10 个 45 闪烁 block |
| participant，参与者 | 独立自然人身份 | 同一人不同日期录制仍是一个参与者 |

研究记录中的 `selection`、`block` 和 `session` 来自各自数据集的定义，不能全局视为同义词。例如公共字符拼写数据的一次集合闪烁可能同时包含多个候选；应读取实际刺激台账。

**R1 与 R5 的直观差别：** R1 看一轮 9 次闪烁就猜一次；R5 看五轮共 45 次闪烁再猜一次。二者随机选一个数字的命中机会都为 `1/9≈11.11%`，但 R5 使用更多 EEG 证据。单轮指标能检验短证据识别，完整 block 指标更接近当前产品任务。

### 2.2 预算的三个数，分别是什么意思

- 产品声明预算：9 个已知目标数字 × 每数字 10 block × 每 block 45 flash = **4050 个有标签 trial，其中 450 个 target**。[S02]
- 公共校准研究预算：**K=0、200、800、2000**，K 是授权的有标签刺激数。它不是 target 数，也不是训练轮数；实际不足时按预声明规则回退，必须报告实际 K。[S02]
- 10 月本人矩阵的剂量：**1/2/3/5/8/10 份完整录制**；最大请求为 `10×450=4500` 次排程，且实际可拟合数还受窗口和 QC 影响。它与上述 4050 次产品采集计划属于不同实验设计。[E01]

C1/C3/C10 在本人剂量矩阵中通常指 1/3/10 份校准录制；某些连续模型记录中的 C68/C500 指其具名校准范围。阅读时先看该 run 的定义，不能从字符串直接推导统一剂量。

### 2.3 EEG、ERP、N2 和 P300

**EEG（脑电图）** 是电极记录的随时间变化的电位差。**ERP（事件相关电位）** 是与刺激事件对齐后可观察到的反应模式；实际单次波形通常包含较强噪声，平均波形与单试次波形需要分别解释。

**N2** 泛指刺激后约几百毫秒内的负向成分，**P3/P300** 泛指其后的正向成分家族；P3a、P3b 是相关但不同的研究概念。具体峰值方向、时间和地形受任务、参考、参与者和处理影响。“N2P3-Net”这个名称表达利用相关时序信息的研究动机，本身没有给出模型已分离出真实生理成分的证据。

**潜伏期（latency）** 是成分相对刺激的时间位置。网络注意力窗中心或分类权重峰值首先是模型参数；只有经过专门的已知位移、振幅混淆和真实数据检验，才能讨论其生理测量含义。早期项目已经据此收紧过 PCW 的解释。[H01、H03]

### 3.3 早期失败为什么值得保留

早期复盘有几组明确的诊断，下一任负责人应理解其机制，而非只记住修复开关。[H01]

**单位与正则化。** MNE 的常用 EEG 数值单位是 V；`1 μV=10⁻⁶ V`。直接把很小的伏特特征送给带 L2 正则的逻辑回归，会改变正则相对于特征的作用。早期窗口逻辑回归加标准化后，GTN balanced accuracy 从约 0.500 回到约 0.564。遇到“模型像随机猜测”，首先检查单位、特征尺度和实现。

**参考会删掉信息。** CAR 是 common average reference，即减去所选电极的平均值。它改变观测空间，不是纯粹的数字居中。早期 GTN 三导例中，Pz 的 target−non-target 差值由约 10.8 μV 变为约 2.5 μV；少导平均参考可能删除共同 P3b。现在的参考选择必须绑定实测电极和采集参考。

**训练 loss 与泛化是两个量。** 早期 242 人开发对照中，50 轮 `hit/AUC≈0.6901/0.6612`，10 轮约 `0.7727/0.7019`；继续降低训练 loss 并没有提高外测表现。该结论属于当时配方，不是所有后续程序都应固定 10 轮的依据。

**滤波器初始化有物理尺度。** 早期随机 FIR 时间滤波器偏向较高频率，采用带通/Gabor 初始化后表征改善。FIR 是有限冲激响应滤波器；Gabor 初始化用有时间包络的振荡核提供频率和时长先验。今天更换采样率或卷积核长度时，仍须换算毫秒跨度。

**决策聚合有自己的统计语义。** 若单刺激分数共同增加常数 c，累计和会多出 `c×该候选曝光数`。曝光不齐时，直接累计未经恰当定义的分数会偏向次数多的候选。分数、membership、缺失和完整请求必须一起审查，不能只对最终输出做归一化。

**可分类不等于可解释。** PCW（参数化成分窗）学习在何时提取特征；它的窗口参数可帮助分类，却不能单凭分类梯度证明真实单试次潜伏期。早期 strict-past 新增分支没有证明稳定增量，正式旧路线保留 `final=PCW`；该规则描述旧版 Neural-RIDE，当前网络另有其显式结构合同。

### 3.4 早期 L/R/Q/S 四对象各负责什么

| 对象 | 要回答的问题 | 当时要求的独立证据 |
|---|---|---|
| L：LatencyMeasurement | 能否测量真实成分时间位置，而非只学习分类窗口 | 已知位移恢复、区间覆盖、初始化敏感度和振幅混淆检查 |
| R：RepetitionEvidence | 重复刺激怎样形成合法的累计证据 | 可加 LLR 主干；新增状态残差须在留出样本上改善概率评分 |
| Q：Reliability | 哪些输入更可信，以及“干净概率”能否成立 | fidelity 排序与明确污染生成模型下的 clean_probability 分开检验 |
| S：InnovationAudit / Stopping | 新分支是否带来额外信息，何时可以少看刺激而停止 | 嵌套模型增量审计、按参与者聚类的重采样，以及先到达阈值的完整 replay |

LLR 是 log-likelihood ratio，即两种解释下似然之比的对数；满足相应条件时可以相加积累。fidelity 是对信号保真/可用性的具名读数；clean_probability 是在明确污染模型下的二元概率，二者含义不同。strict-past 表示只用声明的过去支持；当时接口是预处理 epoch 层面的过去，并不等于原始 SDK 流式因果系统。gate 是启用某项解释或功能前的验收条件；fail-closed 表示条件不满足时关闭该新增作用或明确无效。[H03]

这套拆分留下的长期方法是：先定义要估计的量，再安排匹配的验证。当前连续响应和人群研究沿其自身的数学合同推进，不能把四个旧对象的名字当作现阶段都已通过的清单。

### 4.2 神经判别链

```text
公开 raw EEG + 标签 + 身份 + 通道/时钟
    → 真实输入与准备资格核验
    → 声明预处理的 binary ERP 源视图
    → N2P3Net 监督预训练
    → 本人授权校准 C：统计 / BN / 权重适配
    → 保存自足个人模型及处理合同
    → 独立后续记录：冻结处理与分数
    → 按真实候选 membership 聚合
    → 预测、覆盖、完整请求风险和重放核验
```

**预训练（pretraining）** 是在公共数据上先学习 target/non-target 表征。**微调（fine-tuning）** 是使用本人 C 继续更新部分或全部参数。**scratch** 是相同结构随机初始化、只用同一目标校准范围训练的对照。**zero-shot / K0** 只用源模型与源统计，不拟合本人 EEG 的统计、BN、温度或分类器。[S02]

当前 `src/models/n2p3net.py` 是紧凑的多尺度 EEGNet 风格 CNN：时间卷积 → 空间卷积 → 池化 → 多个时间尺度分支 → 显式读出 → 两类 logits。默认读出名为 `full_unfold`，对保留的特征位置展开后分类。当前构造器以六导、179 点实例化为 **1202 个参数**；这是此次实测的默认构造，不代表旧权重或所有可选结构。历史文档中的 1279 参数和早期 TCN/PCW 应按各自版本解释。[P01、L01]

**logit** 是神经网络归一化前的分数。**BN（Batch Normalization，批归一化）** 同时有可训练仿射参数及运行统计；源、目标、训练与推理的统计来源会改变实际模型。**Split-BN** 为不同域维护分开的统计，必须让 mask 和域身份贯穿所有归一化位置。

公共源训练只要求可靠的二分类标签，不要求每个库都能恢复“猜数字”的候选身份。真正的九选一/字符判定另由物理刺激台账提供候选关系。这使公共 ERP 训练和最终决策能够共享表征，同时保留各自任务语义。

### 4.3 经典专家与融合

| 方法 | 工作方式 | 保留它的原因 |
|---|---|---|
| 波形收缩 LDA | 对切片特征做线性判别，并稳定估计协方差 | 简洁且多次形成强基线 |
| xDAWN | 根据事件相关响应学习空间滤波，再接其具名特征与分类程序 | 检验空间去噪是否提供互补信息 |
| NN source | 公共源初始化后本人适配 | 检验源训练能否减少本人标注成本 |
| NN scratch | 相同结构、本人范围内从头训练 | 给出迁移的匹配对照 |
| 连续 AR0/AR8 等专家 | 对连续响应与相关噪声建立显式模型 | 检验独立 epoch 路线留下的建模问题 |
| 等权概率池 | 各专家先产生完整候选概率，再算术平均 | 研究错误互补；结果依赖各叶节点完整性和概率尺度 |

**收缩（shrinkage）** 把不稳定估计向较简单的结构拉近。**协方差（covariance）** 描述不同特征共同波动；样本较少时，直接估计大协方差容易不稳定。**概率池** 与把所有 raw 分数直接相加不同，具体使用哪种概率程序必须由原模型和 recipe 定义。

十月三专家池明确为 **NN source＋波形 LDA＋xDAWN**。scratch 是单独的比较臂；“三混合”不能理解成 source、scratch 和 xDAWN。四专家对照再加入具名连续专家。池要求的叶节点缺失时按原规则拒判，不能临时少一个专家继续平均而沿用原方法名。[E01]

## 五、输入、设备与信号处理合同

### 5.1 电极和参考：当前物理事实

BrainSync 采集槽顺序为 `Fz/Cz/P3/Pz/P4/PO8/EOG/Oz`：原 PO7 槽实际采 PO8，原 PO8 槽用于 EOG。分类 EEG 有 **Fz、Cz、P3、Pz、P4、PO8、Oz 七导**，EOG 独立保留。公开数据的电极名继续使用其原始声明。[S02、S04]

Fz/Cz/Pz 等是标准电极位置名：F/C/P/O 大致对应额、中央、顶、枕区域；z 表示中线，数字区分侧向位置。它们表示测量位置，不是可以随意互换的特征名称。

用户已确认 BrainSync 的采集 **REF 是左耳耳垂耳夹**，旧 T7/T3 声明属于记录错误。参考电极决定每导的电位差。软件再作 Cz 参考后，常用迁移输入为 `Fz/P3/Pz/P4/PO8/Oz` 六槽；其中 Cz 是被减去的参考，已经不作为独立输出信号。缺测导保留 mask，不通过补零把它变为实测导。[S02]

本人 target-only 的原生七导路径与跨源 Cz 六导路径各有独立合同。比较迁移收益时，要把 source 和 scratch 放在同一输入视图上。原生七导保留更多方向是空间信息判断，是否提高识别仍需配对实验。

### 5.2 采样、窗口和预处理

| 项目 | 现有本人常用声明 | 应核对的含义 |
|---|---|---|
| 原生采样率 | 250 Hz | 设备每秒取得的样本数；USB/BLE 的当前约定 |
| 模型采样率 | 128 Hz | 处理后的模型时间网格 |
| 模型窗口 | `[-200,1200) ms`、179 点 | 起点含、终点不含；由实际离散算子和截长决定点数 |
| 电压单位 | V | 展示 μV 时乘 10⁶，模型、阈值与噪声须同单位 |
| notch | 50 Hz、Q=30 | 陷波，抑制工频附近成分 |
| bandpass | 0.1—30 Hz、四阶 IIR | 限定低频漂移与高频范围；IIR 含递归状态 |
| phase | 新本人常用双向、零相位 | 前后两次处理依赖整段数据；边界和记录可用时刻重要 |
| baseline | 刺激前均值扣除，`mean_only` | 移除该窗口的刺激前平均电位 |

上述取自 `configs/brainsync_bidirectional_preprocessing.json` 与近期本人方案。公共源、旧模型和原生连续研究可以使用不同声明；应读取各自保存的算子，而非用“当前默认”覆盖旧结果。根 README 仍有因果滤波概述，具体本人操作以当前输入合同、工作站指南和实际配置为准。[S04、S07、I03]

**mask** 是逐 epoch、逐通道的有效观测标记。数值数组中的零可仅是占位。统计、数据增强、参考、归一化、分类与评价都必须消费真实 mask，否则会把不存在的电极引入训练。

**滤波状态恢复** 处理的是异常隔离后，递归滤波器初始状态对后续样本的影响。它给出的数值边界只约束其声明的状态误差；持续污染和接触问题需要另行判断。把边缘等待缩短或切段后直接拼回连续记录，会改变输入含义。

### 5.3 启动裁剪：已经落实的输入改动

用户确认设备启动故障后，策略为：从 **首个刺激开始** 排除 4 秒，并向上取整，保证第一个保留 trial 的完整刺激前基线和响应支持都在裁剪之后。裁剪发生在任何滤波、QC 和 EOG 拟合之前。[S04、B04]

本批 14 份 completed 记录均排除最前 3 次刺激，共 42 次。13 份可准入；`P001_20261030_144501_01` 的整份排除保持。派生目录 `mne_data/BrainSync_startup_cut_4s/` 保存未滤波、未重采样 EDF、事件表和原轴偏移。接受记录记载逐值后缀相等、原排程保留，以及 135 项通过、2 项可选集成跳过。[B04、I01]

两个后续动作必须一起考虑：

1. 重新拟合改变支持的 QC/EOG、本人模型和需要变化的完整程序；旧输入下的模型和分数继续以旧身份保存。
2. 重新声明被裁剪事件对应的决策支持和分母。原排程仍为 450，不意味着 450 次都具有 EEG；完整 R5 是否可判应由实际请求台账决定。

### 5.4 三种“质量处理”需要分清

**basic** 已包含合同校验、共同滤波、有效窗口、重采样、基线及参考投影。它不是未经处理的 raw EEG。

**reviewed** 指十月旧矩阵中，绑定到特定 EDF 字节的人工审阅通道区间、平线检测、切段和边界恢复。该 `/5 reviewed_only` 包只有具名记录的适用范围；九月部分输入沿用 basic。旧公共源没有按这批 reviewed 重训。[E01、B03]

**一致 basic/QC 重做** 是十月底另立的比较：十二库 basic 源→basic 本人 C→basic 推理，对照十二库 QC 源→QC 本人 C→同一冻结 QC 推理。实际 EOG 才做回归，无 EOG 的库如实记录。它有自己的原始名单、处理签名与完成状态，不能与旧 reviewed 混用名称或结果。[E01]

QC 是 quality control，质量控制。当前检测主要涵盖跳变、精确平线、逐导支持及滤波边缘恢复；幅值、趋势和相关性也可只作诊断。检测没拒绝某个 epoch，只能说明其通过该规则，不能直接认证为纯脑信号。

### 5.5 当前 EOG 问题及下一步边界

EOG 是眼电信号；本项目用作预处理辅助，不进入 EEG 分类器或头皮平均参考。OLS（普通最小二乘）回归在授权 C/源训练样本上拟合 EEG 与 EOG 的线性关系，冻结系数后扣除其投影。相关的真实 EEG 也可能被一并扣除，因此需要保真和任务评价。[E01、E02]

启动裁剪后的诊断形成以下实证：[B05]

- C1 固定未来测试保留 641/900 个 epoch，其中 228 个超过 1000 μV；basic 同两份测试保留 894/900 个，超过 1000 μV 为 0。
- 保持 C1 最终 QC mask、原分段、滤波和基线，只撤销已冻结的 EOG 扣除，两份测试的超过 1000 μV 计数均由 114 降为 0。
- C1 的 Fz 回归系数为 −7.477，C10 为 +0.113。该差异是稳定性线索；符号本身不作伪迹判决。
- C10 QC 的 5136 个保留 epoch 中仍有 3 个超过 1000 μV。大幅波形的不同来源应分别分析。

下一任负责人应先检验合法 C 内的回归病态、低有效 EOG 变化、跨会话尺度/相关关系及频带一致性，并为候选修订制定源与目标共用的合同。具体采用何种稳定估计或禁用规则属于下一轮研究决策，应在独立未来数据上评价。当前幅值隔离没有完成该修订，也没有产生新分类器效能结果。

### 6.3 文件格式与凭证

- **EDF/BDF/NIX/MAT/CSV**：原始或来源特定的数据容器；格式能打开，还需核单位、参考、标签和时钟。
- **BIDS**：脑成像数据组织规范；EEG 文件配合事件、通道和采集元数据使用。sidecar 是这些伴随文件。
- **NPZ/cache**：从原始数据派生的数组缓存。可复用性由父数据、方法、实际执行和支持范围共同决定。
- **checkpoint / `.pt`**：保存模型或训练状态。日常称“检查点”的任务状态 JSON 与模型权重文件作用不同。
- **manifest**：清单，记录成员路径、大小、哈希和关系；**receipt / acceptance**：执行或接受回执，记录做过什么以及接受到什么范围。
- **SHA-256**：内容摘要，用于检查文件字节是否相同。摘要相同支持内容身份核对；科学有效性仍依赖该内容及其来源关系。
- **producer / consumer**：生成产物的实际源码，与当前读取/使用它的源码。两者可以不同，必须分别留证。

Git clone 主要携带源码、测试、指南和紧凑清单。原始数据、模型、完整运行输出、冻结压缩包和采集端需要单独移交，遵循[归档分发规则](../frozen/README.md)。

## 七、已取得的结果：每项都附任务与分母

### 7.1 早期 GTN：改进来自输入和训练链修复

早期复盘记载，242 人开发 LOSO 中，GLM v3 的 `hit≈0.8388、AUC≈0.7543`；EEGNet 的 `AUC≈0.7620`，同页记两者猜中人数均为 `203/242≈83.8843%`。原复盘另给 EEGNet hit 标量 0.8395，与这一计数略不一致，待取得原 run 后核对具体字段；此处保留明确计数。材料将这些列为开发结果。本次没有重新取得全部当时运行产物或重算统计。[H01]

**LOSO（leave-one-subject-out）** 是每折留出一整个人，其余人用于训练。这里的 scratch 表示随机初始化，训练数据仍可以包含其余参与者；十月本人 scratch 则只用本人 C。这一差别会显著改变分数，比较时必须同时说明训练范围。

### 7.2 9 月统一公共矩阵：迁移有平均收益，复杂包没有全面占优

普通整库留出包含 123 名不同参与者：BI2014a 61、BI2015a 41、BNCI 8、Huebner 13；三个 seed 先在人内平均，再作库内参与者平均和四库等权。精确 K800 仅有 72 人，不足者另列实际 K。[E05]

| 程序 | 精确 K200，123 人 AUC | 精确 K800，72 人 AUC |
|---|---:|---:|
| A0Q0：源 CE＋完整微调 | 0.6947 | 0.7564 |
| A1Q1：完整统一包 | 0.6877 | 0.7478 |
| 同结构 scratch | 0.6534 | 0.7368 |
| 波形收缩 LDA | 0.6925 | 0.7616 |

A0 是普通源交叉熵；A1 加 SupCon 和条件 MMD。SupCon 是监督对比学习，拉近同标签表征；MMD 是最大均值差异，用于约束分布差别。Q0 为普通个人完整微调，Q1 加源中心收缩及有合法 membership 时的决策损失。完整包比较反映整套程序，无法由此拆出单个模块的因果贡献。

## 九、连续生成式研究主线：为什么存在、进行到哪里

### 9.1 研究动机

普通 trial 分类把刺激窗口变成分数，再按候选累计。连续研究希望直接描述：真实刺激历史怎样产生重叠 EEG、噪声怎样在时间和通道间相关、本人校准怎样更新响应，以及这些不确定性怎样影响候选证据。该路线可覆盖九选一及公共 32/36 候选。[S02、E02]

**membership** 是“某次刺激包含哪些候选”的矩阵。例如直接闪一个数字时只包含该数字；行列拼写时一次闪烁会包含多个字符。候选数相同不等于范式相同。把 36 候选事后并成 9 组，也不会自动得到九数字直接闪烁的监督。

### 9.2 用一组公式读懂模型

下式用于理解模型组成；具体拟合以具名程序的完整 law 和坐标为准：

\[
y=X(q)\beta+Z\gamma+\varepsilon,\qquad
\beta\sim\mathcal N(\mu,F_sF_s^\top),\qquad
\varepsilon\sim\mathcal N(0,\Sigma).
\]

- `y`：实际获准的 EEG 观测。
- `q`：当前候选目标，如数字 1—9。
- `X(q)`：由刺激时钟、membership、响应字典及观测算子形成的设计矩阵。
- `β`：响应函数的系数；`μ` 与 `F_s` 表示源提供的均值和不确定性因子。
- `Zγ`：截距、慢漂移等 nuisance（为正确建模而保留、但并非最终目标的参数）。
- `Σ`：噪声协方差。AR(p) 是自回归噪声模型，用前 p 个时刻描述相关性；AR0 则没有该时间递归。

**字典 / basis** 把一条响应曲线写成若干已声明基函数的加权和。**观测算子** 表示参考、电压单位、滤波、重采样或读取支持如何作用于信号。对一个 Gaussian 模型变换观测坐标时，均值和协方差须同步变换。

**似然（likelihood）** 衡量“假定某候选和参数，当前观测有多相容”。**先验（prior）** 表示观测前的参数分布。**后验（posterior）** 是加入授权观测后的更新。**边缘化（marginalization）** 是把未直接关心或未观察到的变量积分/求和掉，并保留其不确定性影响。

某些漂移使用 **flat measure（平坦测度）**，这要求保持物理坐标、维数、积分体积以及候选证据的正且有限。当前规范在相应情形称归一候选证据为“广义后验”；proper（可归一的正规）概率模型和数值 proposal 另行声明，不能混用名称。

### 9.3 C、P、F 与完整证据

**C** 是有授权标签的校准观测，**P** 是当前 held 任务的前缀，**F** 是包含此前缀的完整当前观测；续段可写成 `T=F\P`。同一份 C 和同一 raw 样本在联合似然中只进入一次。

设 `J_P(q)` 和 `J_F(q)` 使用相同原候选先验 `π(q)`、相同 C 和匹配的参数测度：

\[
p_{\rm whole}(q)=\operatorname{normalize}_q J_F(q).
\]

这是完整 block 的主读数。若先由 P 得到后验，再用 `J_F/J_P` 顺序更新，也恢复该完整读数。另一个程序

\[
\operatorname{normalize}_q\!\left[\pi(q)\,J_F(q)/J_P(q)\right]
\]

是以原候选先验重新计权的续段证据比较臂。它与完整读数的区别在于是否保留 P 对候选的更新；当前缀已含目标信息时，二者通常不同。该区别是研究问题本身，下一任应据研究规范保持命名和输出。[S02、E02]

### 9.4 共享响应、人群差异与局部变化

人群学习应消费每个人的实际数据 likelihood。个人 posterior 已经含有该次 prior；若把它当成无误差新观测再次使用，会重复引入信息。人群 forecast 另外保“不同人本来就不同”和“人群均值还估得不精确”两类不确定性。[E02]

G0/G1 是第一项响应机制比较：**G0** 以同一个人的共享完整响应描述多次选择；**G1** 再加入每个 selection 独立的零均值函数变化。共享参数跨 selection 只出现一次，局部变量在同一 selection 的 C/P/F 中保持同一身份。该 Gaussian 函数变化与非线性 delay/width warp（时间延迟/宽度变形）是不同模型。[S05、E02]

## 十二、接任后建议怎样推进

### 12.1 第一阶段：接收和复核，先让材料可恢复

1. 阅读本报告、六指南、C01 总检查点、近期 basic/QC 与 Lean 子检查点；遇到原路径缺失，登记来源和恢复去向。
2. 保存当前 Git 差异和未跟踪文件清单，确定代码、实验和设备各自维护人。早期文字参考随本仓库一并接收，当前主仓库继续是实现入口。
3. 接收原始 EEG/sidecar/session/clock、当前源权重、个人模型、run 归档、producer 快照、采集端和完整发布目录。
4. 从 B01 原归档恢复一条完整“输入→模型→预测→分析”链，验证实际 source/scratch、R1/R5、覆盖和保存重放；先形成可重复的最小闭环。
5. 恢复新一致链的原 checkpoint/readiness，核完整二十四视图及缺失/零行记录；明确哪些工作已完成、哪些需要重新执行。

本阶段的交付物应是：可访问的原始证据目录、来源与摘要相符的恢复清单，以及更新到原检查点的任务状态。

### 12.2 第二阶段：冻结新输入，解决少量 C 下的处理稳定性

先把首刺激后 4 秒裁剪、实际参考、EOG 接法、滤波支持和 QC 适用范围冻结成具名方案。围绕 C1 EOG 问题制定可被反例推翻的假设，再验证：

- 同一合法 C 的系数和 mask 可独立重算；held 信号/标签没有参与拟合。
- 低方差 EOG、弱相关、跨会话幅度变化、持续漂移和缺导不会静默造成巨大输出。
- 原始 EEG、冻结处理输出及注入 ERP 的完整差值均可检查；自适应处理应检验 `T(x+h)−T(x)`。
- basic 和候选 QC 使用同一原始名单，源、本人校准和未来推理保持匹配的方法身份。
- 幅值稳定、覆盖和最终识别分别评价。

新处理的接受出口应同时有数学/数值反例、真实原始处理重放与后续任务读数。保留旧方案原结果，以新 producer 开始新的比较。

### 12.3 第三阶段：完成完整匹配实验

在输入稳定后执行已约定的完整比较：NN source、同构 scratch、波形 LDA、xDAWN，以及明确叶节点的概率池。源和目标各自保存训练、选择、模型及处理合同。每种剂量报告实际 C、target 数、可拟合 epoch、测试名单、R1/R5、完整请求命中、已评分识别和覆盖。

选择规则只在 source/C 内完成；用过去已查看的测试定位问题之后，最终效能由新的独立后续记录评价。各 seed 应按其覆盖的阶段命名：冻结同一源后的三个 target seed，只表示目标优化重复。

### 12.4 第四阶段：分开推进研究主线与产品确认

连续研究先恢复原 source→joint C→history→完整输出链，保存已接受 source 和 C；对 codec 和数值持有期做最小必要修复，取得完整公共 G0/G1 及 whole/conditional 对比。

产品确认另立前瞻方案，明确：参与者与成人身份、完整 1—9 目标安排、4050 校准预算的实际执行、独立后续测试、设备/时钟核验、质量规则、拒判、样本量和统计分析。是否以 90% 为验收边界应在采集前正式定义，而非在单人高分之后回填。
