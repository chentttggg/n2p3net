# N2P3-Net 架构方案评审报告（Review v1）

> 评审日期：2026-08-20
> 评审对象：constitution.md / mission.md / techstack.md / blueprint.md / roadmap.md（下称「五文档」）
> 评审立场：EEG 工程 × 神经网络理论交叉视角；按项目要求「重思考、三思、允许推翻」。
> 结论效力：本报告是建议修订的依据，不直接改动五文档；是否采纳按 constitution 第六节修订规则记录。

---

## 0. 总体判定

**方向成立，细节有错，容量超标，两个数值需要推翻。**

- 「小而聪明」的总体路线（成分查询软读取 + 坐标式通道身份 + 时域多任务 + 决策层累加）与
  小样本/非统一格式/时域三约束匹配，**架构骨架可行**。
- 但按 blueprint 现稿直接实现，有 **2 处数学/内部错误（其一为符号错误）**、**1 处与自身宪法 E4 的
  数量级冲突（约 30–60 倍超标）**、**1 处已证实的生理学风险（0.5 Hz 高通对 P3b 的失真）**，
  以及若干未设防的退化模式（成分查询坍缩、Head-B 监督同源）。
- 修订后进入 Phase 2 的把握较大；不修订直接实现，Phase 2 大概率「被线性基线打平 + 过拟合」，
  恰好落入自己宪法 P8 警告的陷阱。

## 1. 必须修复的错误（P0）

### 1.1 【符号错误】熵锐化损失写反了
blueprint §5 Head-C(3)：
> L_entropy = −H(A_P3b)，防 A 退化为均匀分布

**这是数学错误。** H 为熵，均匀分布使 H 最大。「防退化均匀」= 要 H 变小，损失应为
**L_entropy = +H(A_P3b)**（最小化熵）。现稿的 −H 项被最小化时会把注意力分布**推向均匀**，
恰好与设计意图相反，且与 KL 先验（想收窄）相互打架，训练动力学不可预测。

修复：`L_entropy = λ4 · H(A_P3b)`，λ4 取小值（1e-2 量级）。另注意它与 KL(Gauss) 项功能部分
重叠（两者都控制分布展宽），建议合并为单一「先验 KL + 温度锐化」项，少一个要调的超参。

### 1.2 【内部矛盾】Split-BN 与全 InstanceNorm/LayerNorm 骨干不相容
constitution P6 把「Split-BN 默认开启」定为不可省略组件；但 blueprint Stage 0.4 用
InstanceNorm/LayerNorm，Stage 2 Conformer 用 LayerNorm——**骨干里根本没有 BatchNorm**。
Split-BN 解决的是「BN 统计量跨域泄漏」问题；模型里没有 BN 时该组件是空操作（vacuous）。
而若为了用 Split-BN 反向引入 BN，则是为解药先服毒。

修复（二选一，推荐 a）：
- **(a) 全程 InstanceNorm/LayerNorm/GroupNorm，删除 Split-BN，改用「域条件仿射」**
  （per-domain 可学习 scale/shift 加在 LayerNorm 之后）。逐样本归一化天然不带跨样本统计量，
  域泄漏问题不存在，组件更少，符合 P1。
- (b) 若坚持对齐 AS-MMD 原配方（其骨干 EEG Conformer 含 BN），则骨干须真的引入 BN，
  Split-BN 才有意义。此路线仅在 Phase 3 跨域实验中作为对照保留。

### 1.3 【生理学数值推翻】0.5 Hz 高通对 P3b 有已证实的失真风险
blueprint D2 / Stage 0 把去漂移高通钉死在 **0.5 Hz**。两条独立证据反对：

1. **Tanner, Morgan-Short & Luck (2015, Psychophysiology 52(8):997–1009)**：实测 0.3 Hz 及以上
   高通会在慢成分（原文明列 N2、P300、N400、LPC）**之前制造反极性伪峰**并衰减其幅值。
   P3b 正是文中点名的受害成分类别。0.5 Hz 一阶高通时间常数 ≈ 0.32 s，与 P3b 时长同量级。
2. **工程不可实现性**：0.5 Hz FIR 在 256 Hz 下冲激响应长达数秒，**在 1 s epoch 内做 0.5 Hz
   高通在数学上无效且引入边缘伪影**。必须先对连续数据滤波再切 epoch——五文档未写明这一点，
   属于必踩的坑。

修复（保留 E1 精神，推翻具体数值）：
- **默认 0.1 Hz 高通（连续数据上做，MNE，epoching 之前）+ 逐试次基线校正 + InstanceNorm**，
  三者叠加足以压制干电极 δ/θ 漂移（基线校正 + 逐试次归一化本身就是一阶漂移杀手）；
- **0.5 Hz 只作为消融对照**，且作为「幅值-潜伏期失真的负面对照」写进 Phase 4 验证，
  反而能成为论文里一个干净的 methodological 论点；
- P2 的「网络外允许项」表述同步修订为「重采样 + 连续域高通（默认 0.1 Hz）+ epoch 切分 +
  伪迹剔除（见 1.4）」。

### 1.4 【宪法与技栈矛盾】伪迹剔除没被 P2 收编
techstack 说 MNE 负责「伪迹阈值剔除」，但 constitution P2 规定网络外只允许「重采样 + 0.5 Hz
高通」。伪迹剔除是数据质量步骤不是特征工程，应当允许；现在的宪法条文使 techstack 违宪。
修复：修订 P2 允许项为「重采样、连续域高通、epoch 切分、阈值法伪迹剔除」，并明确剔除阈值
（如 ±100–150 μV，儿童干电极可放宽并记录剔除率）作为数据集元信息记录。

## 2. 与自身宪法 E4 的冲突：参数预算超标（P0）

E4：参数量以 EEGNet（<10k）为量级参照。按 blueprint 现稿估算（D=64，Conformer 3 层）：

| 模块 | 估算参数量 |
|---|---|
| Stage 1 时间卷积银行（4 尺度×16 滤波器，跨通道共享） | ~4k |
| Stage 1 空间深度卷积 + 通道投影 | ~5k |
| **Stage 2 Conformer ×3（FFN exp=4, macaron, MHSA, conv module）** | **~300k** |
| 成分查询 cross-attention（K/V 投影 + 5 查询） | ~8k |
| 各头 + 位置编码 + 归一化 | ~10k |
| **合计** | **~330k** |

**超出 E4 参照 30–60 倍，全部超标额集中在 Stage 2 的 2–3 层 Conformer。** 而 Stage 1 的多尺度
卷积银行（最长核 504 ms）已为每个时间步提供了 ~500 ms 的局部上下文——Conformer 在此任务上
要补的「长程依赖」只剩「N2(200ms)→P3b(350ms)」这一段 ~150 ms 的关系，ROI 极低。GTN 上
CNN≈LDA 的既有证据（Värbu 2019）也指向同一结论：容量不是瓶颈，域差才是（E6 自己也承认）。

**修复：把 Stage 2 深度降级为显式消融轴（depth ∈ {0, 1, 2, 3}），Phase 2 默认 depth=1 且
FFN expansion=2，或以两层膨胀 TCN（dilation 1/4/16，感受野 ~500 ms）替代。** 预算上限建议：
Phase 2 单受试 **≤ 50k**；Phase 3 跨域 + 自监督预训练可放宽至 ~100k 并须归因收益。

> 预期消融结论（可证伪的先验）：depth=0/1 在单受试上打平或优于 depth=2/3；depth 的收益
> 若存在，只应出现在跨数据集迁移上。若实测相反，回改本报告。

## 3. 高风险设计与未设防的退化模式（P1）

### 3.1 成分查询坍缩（query collapse）
5 个查询共享同一 1-bit 监督（只有 H_P3b/H_P3a/H_N2 进头）。DETR 系的已知失败模式：无
匹配监督或无差异化先验时，多个查询学成同一个注意力分布。现稿只给 A_P3b 设了 KL 先验，
**Q_N1/Q_P2 完全无监督、Q_N2/Q_P3a 无先验**，坍缩几乎必然。

修复（三层防线）：
1. **每个查询独立先验**：L_prior = Σ_c KL(A_c ∥ Gauss(μ_c, σ_c))，中心按 3.3 的年龄自适应取值；
2. **成对散度惩罚**：L_div = Σ_{c≠c'} JSD(A_c ∥ A_{c'})，防两查询注意力重叠；
3. **砍查询数**：Phase 2 只保留 3 个进头/进损失的查询（N2、P3a、P3b）；N1/P2 无监督必然
   退化成任意模板，若 Phase 4 要展示，也只作「展示用、不进损失」的旁路。

### 3.2 Head-B「N200 辅助」的标签与 Head-A 同源
Head-B 的监督还是 target/non-target 这 1 bit——它不是新任务，是**同标签的早期证据集成头**
（multi-view ensemble + 正则）。这不是错，但「N200 辅助判据」的命名会诱导对其贡献的误读；
且无任何机制阻止它从 P3 尾巴泄漏信息后冒充「N2 判据」。

修复：① 改名为「早期证据头」并在消融表中如实归类为集成/正则；② 结构上限制其输入 token
为 t < 300 ms（配合 A_N2 先验 ~200–250 ms），强制其证据真的来自早期窗；③ 与 Head-A 的
「不确定性加权」在数千试次下难以稳定拟合（log-variance 需多轮），建议退化为固定
λ2 ∈ {0.1, 0.3, 0.5} 网格。

### 3.3 Stage 0 可学习参考矩阵 R ∈ R^{C×C} 自由度过大
自由的 C×C 矩阵 = 输入端一个任意空间滤波器，会与 Stage 1 的空间卷积耦合竞争，且
「参考无关」的可解释声明失守。8 电极的「局部平均参考」本身也不是真 CAR（稀疏蒙太奇、
顶区偏置），声称参考不变过强。

修复：**重参数化 R = I − w·1ᵀ，w ∈ R^C 过 softmax**（≈9 个参数），语义即「可学习加权
再参考」；可选加每通道增益（8 参数，吸收设备增益差）。另需诚实声明：再参考变换只能
统计意义上吸收参考域差（训练时混合多参考数据 + 下述增强），不构成严格不变性。

### 3.4 【新增增强】参考抖动（reference jitter）
训练时对每试次以概率 p 随机重参考到随机通道（或随机凸组合），零参数、直接教会网络
参考不变性，比可学习 R 更符合 P1。与 R 重参数化并用。

### 3.5 先验中心是成人中心的，被试是 7–17 岁儿童
Gauss(μ=350ms, σ=150ms) 对儿童偏早：发育文献（Naganuma 1991；Tsai 2012；Gupta & Prasad
2025 视觉 oddball）一致显示儿童 P300 潜伏期随年龄线性递减 ~7–10 ms/年，5–7 岁视觉 P300
可达 ~383 ms 且个体差异大；N2 同步偏晚。7–17 岁跨度下固定 350 ms 中心会让先验把 τ̂ 系统性
拉早、把 A 的质量推向错误位置。

修复：**先验中心从数据初始化**——用训练集 grand-average 差波（target−non-target，Pz 通道）
的峰位初始化 μ_P3b、μ_N2；σ 放宽（N2/P3b 各 ~40–60 ms 增量）。年龄作为协变量进入
Phase 4 的 LIMO 单试次回归（本就该做）。

### 3.6 决策层：平均概率浪费置信度信息
「累加/平均 p_target」把 p=0.99 与 p=0.55 同权。条件独立下贝叶斯正确的累积是
**对数似然比（logit）累加**：score(d) = Σ_trials logit(p_target)。且跨被试/跨会话的
系统性校准偏差会扭曲累积——需**被试内标准化**（每被试用全部 9 个数字的 score 分布做
z-score，P300 speller 动态停止领域的标准技巧）。

### 3.7 类不平衡与切分泄漏
target 占 ~1/9（数测试次里正例可能只有数百），BCE 无 pos_weight 会学到「全判非目标」。
五文档均未提。修复：pos_weight ≈ 8（或 focal loss）；评估按 D3 用 balanced acc/AUC。
另外 Phase 2「单受试多次本体训练」必须**按 run/会话分组切分**（同 run 的试次共享时漂与
噪声状态，混切会虚高）——roadmap 未写明，属验收协议漏洞。

### 3.8 自监督预训练的量级诚实性
自有数据数千试次不足以支撑掩码重建学到有意义表征（LaBraM 2500 h）。可行的量级来自
GTN（250 名被试 × 数百试次 ≈ 数万试次，仅 3 导）。**SSL 语料 = GTN + ERP CORE + 自有无标签
数据，靠坐标嵌入 + 通道掩码吃异构通道**；预期收益定为「小正则」，排在基线与 1–7 项之后，
Phase 3 再上，符合其「可选」定位。

## 4. 三思记录（本评审推翻了什么、保留了什么、为何）

**考虑推翻「Conformer 编码器」→ 部分推翻。** 证据链：Stage 1 卷积银行已覆盖 500 ms 上下文；
GTN 上 CNN≈LDA；E6 自认跨域单试次天花板 0.61–0.66 AUC（域差瓶颈，非容量瓶颈）。结论：
不彻底废除，降级为 depth∈{0..3} 消融轴、默认 1 层瘦身版或膨胀 TCN。保留理由：EEG
Conformer/ATCNet 在跨被试上有正证据，跨域 Phase 3 或有用武之地。

**考虑推翻「0.5 Hz 高通」→ 推翻数值、保留精神。** Tanner 2015 的反极性伪峰证据 + 1 s epoch
内 FIR 不可实现两条独立理由。E1 的「去漂移必须做」保留，工具改为 0.1 Hz 连续域高通 +
基线校正 + InstanceNorm 组合。

**考虑推翻「多任务头」→ 保留但重新定性。** Head-B 标签同源使「辅助判据」的说法不诚实，
但其集成/正则价值真实（文献 S4–S6 支持多成分，机制上以结构约束实现而非新监督实现）。
重定义后保留，加 t<300 ms 输入限制。

**考虑推翻「成分查询机制」本身 → 保留。** 它是全方案里信息密度最高的设计（软时间窗 +
潜伏期读出 + 可解释输出三合一），替代品（硬窗特征或纯注意力池化）各丢一角。需要的不是
推翻而是补防坍缩正则（3.1）。

**考虑推翻「可学习参考矩阵」→ 推翻形式、保留意图。** C×C 自由矩阵改为 9 参数加权再参考
+ 参考抖动增强，意图（参考无关）不变，手段从「让网络学」改为「教网络不变」。

## 6. 对 mission 目标数值的意见

- 跨受试零样本 ≥78%：目标本身只是复现 2016 年 3 导 MLP 的水平，现实；但注意 77.2% 是
  GTN（湿电极、教室、3 导）数字，与自有 8 导干电极不可直接比——验收应改为「在 GTN 上
  复现 77%±3，在自有数据上报告绝对值并回填」两档。
- 单受试 ≥85%：依赖每数字试次数 K（R2 已列），建议把 K 写进验收表（如 K≥30 时 ≥85%）。
- 跨数据集 AUC ≥0.70：GTN（儿童）↔ ERP CORE（成人）叠加了年龄域差，风险最高的一个
  目标；建议增加中间档「GTN 内部按年龄分层」先验证年龄 shift 单独的贡献。
