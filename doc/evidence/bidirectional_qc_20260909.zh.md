# 双向滤波与QC联合优化

2026-09-09。用户明确确定应用双向滤波，以减轻漂移。本轮据此将完成记录的双向处理接入
个人校准、推理和QC；此前四会话LDA比较继续作为已观察的开发证据，不限制本轮实施方向。

## 算法与误差定义

原始差分、滚动范围、恒值和真实采集断点在重参考/滤波前判断。慢漂移是连续诊断，
双向高通衰减低频；原始大幅度及滤后变平均不单独证明好坏。正常休息保留真实时间轴。
严重异常按通道及参考/EOG依赖隔离，在各最终输出导的完整干净连续段内执行实际SOS双遍。

设段长N，J为时间反转，F_N为零初态单遍滤波矩阵，O_N[n]=C A^n。
将实际MNE有限延拓折叠成开始消费真实段时的前向状态zL，以及反向消费段末真实样本前的
后向状态zR。局部处理相对较长干净上下文参照的误差严格为：

```text
delta_y = J F_N J O_N delta_zL + J O_N delta_zR
```

delta_zR必须从实际第一遍结果和右侧延拓推导，包含前向误差对第二遍输入及初态的耦合。
不能独立初始化两个相反方向的原始信号后简单相加。
令A=V diag(lambda) V^-1，校准模态包络为GammaL/GammaR，L_e为真实epoch截取、FFT重采样、
179点截断及均值基线算子，则每导逐epoch的条件界为：

```text
B_e,c = max_j [sum_k abs((L_e J F_N J O_N V)[j,k]) GammaL[c,k]
              + sum_k abs((L_e J O_N V)[j,k]) GammaR[c,k]]
```

该界依赖段长和epoch位置，不预设单调性，不把旧单向等待时间机械地放到两端。
完整配对状态仅在明确干净校准区间的人工裁剪探针拟合，推理不更新；包络是经验不确定集，
只在实际状态误差落入集合时提供数学保证，不认证所有未来EEG或持续污染。
参考/EOG先线性混合、再按依赖并集分段滤波，允许以abs(W)投影两个包络。
若将来改变为各原导先按不同段滤波，则需逐父导实际N/位置计算界后再投影。

自然记录/真实采集段的两端是确定的有限记录处理合同。与较长参照不同不能单独证明信号坏，
所以新QC默认`boundary_action=artifact_edges`：未被伪迹切段的完整采集段只记录端点敏感度；
片段只要任一端由伪迹隔离产生，就保留完整双端条件界作硬门。不得只保留“有伪迹那一端”的
状态项，因为后向状态中包含前向误差耦合。`all_edges`保留为明确的严格控制，缺字段读取旧义。
原始范围默认`range_action=diagnostic`，超阈次数和原阈值照常保存；差分突变和持续恒值仍硬标记。

独立数值脚本已验证：N=2500/500时与MNE实际输出逐值一致；两有效状态重建误差分别
4.07e-16/2.06e-16 V。漏掉后向状态项会漏约272μV误差；六个实际epoch盒界均覆盖注入。
每原导各0.75μV界、减参考达到约1.5μV的反例已通过，不能按单原导容差放行差分导。

## 文献依据

[EEGLAB Filtering](https://eeglab.org/tutorials/05_Preprocess/Filtering.html)说明强伪迹应在滤波前处理，
边界两侧独立滤波；[MNE Raw.filter](https://mne.tools/stable/generated/mne.io.Raw.html)按显式注释前缀
隔离段，普通BAD注释并不自动隔离。[MNE annotate_amplitude](https://mne.tools/stable/generated/mne.preprocessing.annotate_amplitude.html)
明确相邻样本差不能检测整个DC平台。

Widmann与Schröger 2012，[10.3389/fpsyg.2012.00233](https://doi.org/10.3389/fpsyg.2012.00233)，
全文区分滤波平滑和可改善的振铃，影响需相对实际噪声衡量。
Kessler、Enge与Skeide 2025，[10.1038/s42003-025-08464-3](https://doi.org/10.1038/s42003-025-08464-3)，
全文覆盖ERP CORE七实验40人2592预处理路径：高通、清理和解码效果存在交互，清理可能
同时去除可解码的结构化伪迹；P3等可出现基线解码伪迹。故本轮同时报告信号保真、覆盖、
残余污染和分类表现，不按其中一个指标定义“全部更好”。
Gustafsson 1996，[10.1109/78.492552](https://doi.org/10.1109/78.492552)，初态对称化不提供未知
记录外样本；SciPy sosfiltfilt不接受method=gust。本实现继续采用数值稳定的SOS及明确边界策略。

## 漂移和ERP保真

实际生产算子保持0.1–30Hz、50Hz/Q30、128Hz和179点均值基线；未提高高通截止。
480秒已知1000μV正弦漂移在中央120–360秒拟合正余弦幅度，与SOS理论响应一致：

| 漂移频率/Hz | 单向残留/μV | 双向残留/μV |
|---|---:|---:|
| 0.03 | 8.0065 | 0.0641 |
| 0.05 | 61.7882 | 3.8178 |
| 0.08 | 377.5507 | 142.5446 |

接近截止的漂移仍可能明显；不能把双向写成所有漂移均消失。
九种8μV高斯ERP（潜伏期0.3/0.5/0.8秒、宽度0.06/0.12/0.22秒）走实际epoch链：
无漂移形态RMSE单向0.785–3.117μV、双向0.0043–0.0446μV；加入1000μV、0.05Hz漂移后，
相对无漂移真实ERP的RMSE单向10.652–13.013μV、双向0.296–0.347μV。
这是所测信号的保真与抗漂移证据，不能代替真实识别率。

## 计算优化和复核

真实第五记录的剖析显示边界评估重复5430次epoch变换、约11万次FFT。
实际`L_e`线性算子用单位基生成并缓存，后续用矩阵乘法；临时单位基工作集限制8MiB，
epoch矩阵缓存4项、有限段模态响应缓存2项。128/250/500.5Hz反例核验真实采样端点与线性等价。
同一数据、单BLAS线程，预热后两次完整加载/QC中位时间由6.4747秒降到2.4463秒，2.65倍；
所有X、通道mask及事件支持逐位一致。该基准含实际raw加载、QC和epoch，不是局部FFT计时。

新模型/旧源签名不混用；zero同raw内校准/验证拆分显式拒绝，即使旧账本误称可提前取得证据。
缓存进入个人QC也检查双向恢复合同，防止绕过raw入口复用旧单向QC。
Windows并行进度记录读锁曾使全套检查失败，统一原子替换增加最多0.63秒有界重试；
永久失败仍保留旧结果并清理临时文件。模型拟合与优化后重放分别绑定实际源码。
