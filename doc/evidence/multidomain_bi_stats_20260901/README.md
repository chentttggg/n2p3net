# BI-source-stat BI+BNCI evidence

This compact audit package records the post-result normalization-scope arm. The
uniform BI+BNCI rows, batches, and optimizer steps were retained while checkpoint
input mean/std used only non-holdout BI source rows inside each legal training
split. The arm was frozen after both parent experiments were known and is
exploratory.

The original cloud archive had SHA-256
`34efadbd8bc42d8dfabf8268308dc358f692092fd3ff83e94cc9092b1cb042e6`.
This directory contains aggregate analysis, checkpoint metadata, logs, manifests,
and hashes. It does not contain source `.npz`, checkpoint `.pt`, or per-run result
JSON objects and cannot independently rerun the experiment.
