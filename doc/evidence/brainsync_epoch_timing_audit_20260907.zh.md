## 模型窗口

`EEGDataContract -> PreprocessingSpec` 固定分段边界。
`t[j]=-200+1000*j/128`，`j=0..178`；首点 -200 ms、末点 1190.625 ms，基线 26 点。
0 ms 位于索引 25/26 之间，不能按 250 Hz 或闭端点 `linspace(-200,1200,179)` 绘制缓存。

ST 使用居中 padding、固定 K35 沿整段滑动，权重学习，首末点跨度 265.625 ms。
MST 局部跨度 125/500 ms，总感受野跨度 414.0625/789.0625 ms，均不是相对刺激的绝对时窗。
`full_unfold` 展开两支各 44 个时间位置，共 176 特征，由分类权重学习位置作用；
不等于自动校准错误事件或移动 epoch 边界。
可选 LMBC 的固定候选窗为 `[150,500)`、`[200,550)`、`[250,600)`、`[300,650)`、
`[350,700)` ms，学习的是注意力，边界和偏移集合不学习，坐标指卷积后的特征。
当前 `SubjectAdapter` 明确不支持此 `ModuleList` 读出，已检查五个源模型均未使用它。

## 采集侧问题

### P1：录制零点未绑定首个样本

`gtn_workstation/runtime.py:1058` 的 `_wait_for_recording_data()` 在计数非零后返回当前
`time.monotonic()`，`_start_ble_recording()` 将该观察时刻设为录制零点。
它不是首个样本的采样时刻。`subscribe_eeg_data(handle,250,...)` 第二参数为批量大小，
SDK 文档/类型描述声明缓冲达到该数量才派发，250 Hz 下覆盖约 1 秒；计数也可能来自 SDK
统计，因此不能给历史会话统一套用“恰好偏 1 秒”。
执行当前方法的反例：sample 0 在 100 s，观察时刻 101.05 s，刺激在 105 s，真实潜伏期
350 ms。代码 marker 为 3.95 s，反应在文件中为 5.35 s，表观潜伏期 1400 ms。
这证明零点语义会影响 ERP；该情形使波形更晚，不能直接解释早峰，也不是历史偏移实测。

### P1：连续性通过不能排除毫秒级缺口

`ui.py:1292` 在回调延迟不超过 12 秒时返回，`quality.eeg_continuity.passed`
只反映此告警门槛。`_on_eeg_batch()` 顺序追加电压，未在此路径验证/持久化逐包时钟和
缺失样本索引。转换异常会丢整批、发出错误；UI 记录错误但继续采集，未建立时间断点。
执行当前方法的反例：250 包中第 18 包转换失败，整批写入 0 点。
五份实际原始账本没有 `device_error` 行；反例不是这些记录曾发生异常的证据。
若累计少存 `m` 点，后续信号相对墙钟 marker 提前 `m/250` 秒，50 点即可产生 200 ms
提前，但没有逐包账本，不能据此给本轮数据归因。日志时长减 EDF 时长约
-0.100/-0.104/0.616/0.809/0.840 秒，起止日志含收尾延迟，不能当作校正量。

## 分段复算

loader 取 BIDS sample 并加入 `raw.first_samp`，传 `tmin=-0.2,tmax=1.2` 给
`build_subject -> preprocess -> mne.Epochs`。先连续滤波，再切源 250 Hz 的 351 点闭端点
epoch，FFT 重采样到 128 Hz，保留前 179 点，减去 `[-200,0)` 均值。
休息用于排除相交 epoch，没有先删休息再拼接滤波。

- 五份原始与准备 EDF 的采样率及全部通道电压样本相同。
- 2250 个 BIDS onset 与原始 JSONL onset 一致到序列化精度，sample 取整最大误差 2 ms。
- SciPy 独立设计 Butterworth SOS、连续滤波、显式整数切片、MNE FFT 重采样及显式基线
  复算全部 2205 epoch，最大差 1.862e-9 V，为 float32 舍入量级。
- 复算七导按既有 Cz 重参考后，与六导缓存逐位相同，标签相同。

| 源脉冲实际位置 | 无滤波重采样 | 零相位滤波后 | 当前前向滤波后 |
|---|---:|---:|---:|
| 0 ms | 3.125 ms | 3.125 ms | 18.750 ms |
| 152 ms | 151.563 ms | 151.563 ms | 167.188 ms |
| 352 ms | 354.688 ms | 354.688 ms | 370.313 ms |
| 600 ms | 596.875 ms | 596.875 ms | 612.500 ms |

无滤波/零相位误差小于一个模型样本；前向滤波在这些脉冲上延迟约 12.5-18.8 ms，
未把 350 ms 移成 150 ms。真实多成分波形峰形变化不是恒定延迟，不能据此统一补偿。
