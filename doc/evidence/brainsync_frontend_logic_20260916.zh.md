| 范围 | 具体触发与旧行为 | 修复后 |
|---|---|---|
| 预览滤波 | 1000Hz、0.1–10Hz眼电直接型IIR数值发散；标准差20µV的30秒噪声输出峰值约1.09×10³⁷µV | 使用二阶节SOS状态实现；同一输入峰值26.70µV，尾段EOG标准差2.925µV；分批与整段状态连续性通过 |
| 预览采样率 | 修改但尚未下发的采样率选项被显示滤波采用；采集改变设备采样率后预览沿用旧率 | 显示滤波及波形时间窗按实际设备readback同步 |
| 操作许可 | 预览切换未进入busy；配置中可断开/启动阻抗；modal确认期间状态改变仍提交实验或通道配置 | 在启动前及modal返回后重新核对运行状态；显示和操作入口同步拒绝冲突 |
| 准备与迟到动作 | 首帧前停止无法取消准备，取消后busy不释放；失败准备遗留目标；继续后迟到discard设置丢弃标志 | 准备任务done回调清理所有终态；目标只属当前请求；非暂停状态忽略迟到discard |
| 阻抗与分析 | 负阻抗判合格；切换到不存在的分析路径保留旧恢复按钮 | 负值明确无效；加载新路径先清旧表格和恢复许可 |
| 设备资源 | 同拍两次start覆盖第一录制器；启动中掉线仍订阅空句柄/返回成功 | 单启动owner，申请前后绑定句柄；停止取消同一owner |
| 掉线数据 | 意外Disconnect后旧缓冲被下一次录制覆盖 | 先保存已有样本；保存失败保留writer并阻止覆盖 |
| 超时迟到命令 | 首个stop worker超时，重试成功后它迟到地停止新预览 | 追踪原生命令真实终态，未结束时维持recovery，禁止并行重试/新启动/断开 |
| 完成通知 | finished时runner仍running；练习开始后同拍停止没有终态 | coroutine及其资源真正结束后发布一次完成通知，订阅者可立即启动下一任务 |
| 采集收尾 | prepare错误清理已有会话；重复pause重复边界；block休息中停止缺block_id而导出失败 | 拒绝已有会话，暂停幂等，合成rest_end保留block身份 |
| 录制失败 | 标记写入错误被吞，源文件缺失或仍在录制的stop失败误报健康；recording_end失败不释放store | 保存可保留的原数据，降级为recording_error并释放会话供恢复；保留已落盘且READY的SDK清理警告语义 |
| 存储事务 | 其他实例恢复/改标签可改变活动会话；失败的内存manifest改动在下次写入泄漏 | OS活动租约防外部操作，崩溃自动释放；读确认互斥；发布成功后才更新内存 |
| 废弃与清理 | rmtree失败仍有成功墓碑；journal.close失败留下活动上下文 | 真实删除后才写成功墓碑；关闭错误仍清上下文和租约，失败记录保留aborted状态 |
| 结果展示 | 图表解析失败仍显示数字/留下已核验模型；同步启动失败停在正在判定 | 清理所有部分应用状态，显示明确失败；需要事后确认时保留原请求身份的无判定结果 |
| 反馈 | 同session_id不同路径覆盖反馈；拒判写成预测错误 | 路径、请求、受试者、已保存目标共同匹配；无判定时correct=null，保留失败分母但不冒充错猜 |
| 报告 | 重试丢冻结处理参数；取消写盘失败跳过进程回收；畸形请求卡队列；目录身份变化或损坏报告仍被接收 | 重试原请求，失败不降级；总是回收进程；失败可见且队列可继续；核对身份，损坏报告清空展示 |
