## 主要结果与后续取舍

保留完整微调作为目标端主线。六种受限更新/轻量适配都未超过强full；时间组更新的
平均收益大于空间组，但同时开放两组的收益并非简单相加。源端SupCon在K200出现小幅
平均收益，暂保留为候选；MMD本配置不晋升。没有修改工作站默认模型。

下表为普通整库留出、K200、三个完整流程seed先在人内平均、库内人均后四库等权的AUC，
覆盖123名参与者。区间与显著性只条件于本次拟合源模型和固定开发库。

| 目标处理 | AUC | 相对full的差 |
|---|---:|---:|
| 完整微调full | 0.72494 | 0 |
| 从头训练scratch | 0.71068 | −0.01426 |
| S1T1：空间和时间均更新 | 0.70696 | −0.01798 |
| S0T1：时间组更新 | 0.69977 | −0.02517 |
| 波形LDA | 0.69175 | −0.03319 |
| S1T0：空间组更新 | 0.69088 | −0.03406 |
| 仿射参数+读出头 | 0.67468 | −0.05026 |
| 残差适配器+读出头 | 0.67108 | −0.05386 |
| S0T0：读出头 | 0.66837 | −0.05657 |

full−scratch为+0.01426，95%配对bootstrap区间[+0.00907,+0.01958]；full−LDA为+0.03319，
区间[+0.02304,+0.04493]。同一BN-affine冻结/dropout关闭条件内，空间主效应+0.01485，
时间主效应+0.02374，交互−0.01532；对应区间分别为[+0.01062,+0.01882]、
[+0.01509,+0.03090]、[−0.02048,−0.01029]。负交互表示增益有重叠，不能解释为两组一起更新更差。

S1T1与full还存在BN-affine和dropout策略差异，因此不能把−0.01798全部归因于某一类参数。
残差头相对冻结头有+0.00271，但距离full仍为−0.05386。家族排除分析中，full同样优于全部受限处理。

源端比较保持同一full目标处理：

| 源目标函数 | K200 AUC | 相对CE的ΔAUC | 95%配对区间 | Holm调整p |
|---|---:|---:|---|---:|
| CE | 0.72494 | 0 | — | — |
| CE+跨域SupCon | 0.72881 | +0.00387 | [+0.00077,+0.00698] | 0.04212 |
| CE+条件MMD | 0.72288 | −0.00205 | [−0.00442,+0.00023] | 0.15494 |

SupCon的三个配对seed增益分别为+0.00211/+0.00694/+0.00256，但存在明显异质性：
BI2014a/BI2015a/BNCI/Huebner分别为+0.01075/+0.00434/−0.00372/+0.00410。
47/123人相对CE下降，按库等权的负增益比例为47.4%，参与者差值p10为−0.01689，最差为−0.06828。
因此小幅平均增益不能作为普遍替换CE的依据。

同时排除BI家族后，SupCon的K200增益为+0.00373，区间[−0.00022,+0.00778]，Holm p=0.14084；
BI2014a的差转为−0.00145，BI2015a为+0.00891。该敏感性同时改变来源组成和源数据剂量，
不能仅凭差值变化指认数据泄漏。MMD在家族排除下为+0.00251，区间同样跨0，说明其方向依赖来源组成。

普通留出下SupCon在K800/K2000的增益为+0.00221/+0.00127，两者区间都跨0；
MMD为−0.00040/−0.00128。K800仅59人，K2000仅21人且来自两个库，不能把这些均值直接当成
123人四库的共同学习曲线。实际K回退、共同队列、逐seed/逐库、负迁移尾部与全部失败分母均在结构化分析中保留。

多重比较采用参与者成组、库等权的双侧符号翻转（50,000次、seed20260916）与Holm调整，
假设零假设下成对差值可作符号交换；P1预声明19个K200对比，P2主对比族为SupCon−CE和MMD−CE。
家族敏感性单独成族。10,000次bootstrap区间作为描述性配对区间，不是跨新研究库的保证。

后续顺序及完整因素矩阵以[统一模型方案](unified_model_plan_20260916.zh.md)为准。
本轮冻结配方提供强full对照及待解释的BN-affine/dropout因素，没有检验有限源中心收缩、
残差、联合源损失与个人决策损失的组合贡献，不能据单模块负效应取消组合实验。
全trunk更新下的BN-affine×dropout归因和合法EA可沿已声明的后续成对设计推进。
本轮仅测试辅助权重0.05，不能据此否定其他MMD配方。
公开单向、无陷波结果不能直接晋升工作站双向算子下的成人九选一程序。
