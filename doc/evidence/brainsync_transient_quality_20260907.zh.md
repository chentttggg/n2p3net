## 对上一轮结论的限定

上一轮证明了分段时轴、重采样与缓存一致，没有证明预处理后的生理形态可信。
本轮确认：IIR 数值计算稳定，但当前处理链缺少对原始大阶跃及其恢复期污染的识别和处置。
`filter_continuous` 只在文件开始和显式 `EDGE` 边界重新初始化；样本中的未声明大阶跃会
进入连续滤波状态。首样本稳态初值只能避免常数初始电位造成的瞬态，不能消除后续真实阶跃。
现有 pilot 没有拟合 EOG 或学习型 trial QC，展示的原始参考均值也没有做伪迹剔除。

## 第三份：启动阶跃导致长恢复尾部

原始 EDF 的第 82 点，即 0.328 s，Pz 单样本跳变 **14207.9 uV**；
同期 Fz 跳变 18047.5 uV，Cz 跳变 24135.4 uV。其物理成因尚未确认。
首个刺激到 3.064 s 才出现，因此这不是首个刺激锁定的 P300。
0.1 Hz 四阶因果带通对这个阶跃有数秒至更长的恢复响应，污染后续 epoch。

| 指标 | 实测原始/当前滤波 | 仅内存中消去该阶跃的诊断反例 |
|---|---:|---:|
| 第一 epoch 原始 Pz 峰峰值 | 89.54 uV | 去基线后与原始逐点相同 |
| 第一 epoch 滤波后 Pz 峰峰值 | 3663.58 uV | 50.32 uV |
| Pz 目标减非目标在 800-1200 ms 均值 | -28.84 uV | +0.34 uV |

反例仅从阶跃点之后减去观测的单样本跳变量，所有文件保持原字节。
各原始 epoch 的基线校正波形保持相同，但滤波后异常消退，直接证明污染来自 epoch 之前的
阶跃经过因果滤波传播，而非 epoch 起点计算或 FFT 插值错误。
这不是自动去阶跃算法：持续阶跃假设、误检、合法参考变化及过渡支持域仍需独立验证。

进一步只作诊断地不平均第一个 block，Pz 晚期差异由 -28.80 降至 +1.54 uV。
这不是按目标波形选择删除 block 的规则；第八 block 也有局部大幅污染，不能认定其余全部合格。

## 第五份：局部污染加共同参考成分

原始信号已有明显局部瞬态；例如 `B002-T002-A001` 的 Pz 原始峰峰值约 1411.76 uV，
当前滤波后约 1439.35 uV，不是重采样凭空产生。
最后一个 block 原始信号存在显著共同慢变及多次突变，其 Pz 晚期差异约 86.82 uV。
仅在诊断均值中移除最后一个 block，全会话晚期差异由 +9.97 变为 +1.29 uV。
其他 block 也有污染，因此既不能直接删除整份，也不能以删掉末 block 宣称清理完成。

| Pz 目标减非目标波形 | 原始参考 | 已有模型使用的 Pz-Cz |
|---|---:|---:|
| 800-1200 ms 均值，源 250 Hz | +9.94 uV | -0.59 uV |

## 为什么不以回零或平滑为删除标准

基线只保证刺激前均值为零，不约束刺激后值。即使输入为干净的 10 uV 高斯正波，
当前因果带通输出在 800-1200 ms 也有约 -1.74 uV 尾部；这属于高通响应，不能要求每个 epoch
结束前严格回到零。本例滤波器最大极点模 0.999043，小于 1，35 秒后响应绝对值小于
0.000259 uV，因此这里不是数值发散。
30 Hz 低通在 15/20/25 Hz 的幅度增益仍约 0.999/0.985/0.912，自然不会画出完全平滑的曲线。
为了图形好看改成 15 Hz，或者提高高通让末端回零，会改变 ERP 幅度、峰形和潜伏期，
不能据此选择生产参数。本轮这些变体只是定位问题的对照，不是替代配方。

第三、第五份原始参考 Pz 差异波在源 250 Hz 与模型 128 Hz 之间的相关分别为
0.999956/0.999832，插值对照 RMSE 约 0.099/0.095 uV，排除重采样制造主要震荡的解释。
