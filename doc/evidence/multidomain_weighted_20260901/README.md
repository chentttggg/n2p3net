# BI-weighted BI+BNCI evidence

This compact audit package records the post-result BI 3x / BNCI 1x exposure arm
and its paired comparison with the parent BI-only and uniform-joint arms. The new
arm was frozen only after the uniform-joint negative result was known, so it is
exploratory rather than confirmatory.

The original cloud archive had SHA-256
`ad4d62dbc89a079cc2676607d5275f3059466c7a51df11bdbea61c137504ad6d`.
This directory contains aggregate analysis, checkpoint metadata, logs, manifests,
and hashes. It does not contain source `.npz`, checkpoint `.pt`, or per-run result
JSON objects and cannot independently rerun the experiment.
