# Decision loss 的导数与前缀风险

[源码先定合同](../assets/lean_loss_20261018/source_contract_01.json)来自实际
`decision_loss.py` 和 `candidate_evidence.py`。本片证明有限实数张量上的 CE、
候选前缀均值、decision 均值及 prefix 权重的数学关系。
[验收收据](../assets/lean_loss_20261018/acceptance_01.json)记录本片的固定执行身份；
当前总进度只在[活动 checkpoint](../assets/lean_gaussian_20261016/active_checkpoint.json)维护。

| 模块 | 定理数 | 已审性质 |
|---|---:|---|
| DecisionLossCalculus | 8 | 从 exp/log 和有限和推导 CE 方向导数、单 score 导数、全相等 score 的正 CE |
| DecisionLossReduction | 6 | 前缀未来行隔离、decision/prefix 求和交换、非负风险、final/uniform 权重语义 |
| DecisionLossChain | 4 | 原始 evidence 方向经前缀求和、均值和温度传至完整 packed risk 导数 |

实际 packed 公式为

\[
s_{d,c,r}=\frac{\sum_{q=0}^{r}e_{d,c,q}}{(r+1)\tau},\qquad
L=\sum_r w_r\frac1D\sum_d
\left[\log\sum_c\exp(s_{d,c,r})-s_{d,y_d,r}\right].
\]

证明先从合法有限分区的正性推导 log 导数，再得到
\(d\ell=\sum_c p_c\,ds_c-ds_y\)，最终把实际
\(1/(r+1)/\tau\)、decision 均值和 prefix 权重完整带入。
不以“autograd 返回正确导数”或整个 loss 成功作为前提。

[独立复审](../assets/lean_loss_20261018/independent_review_01.json)核对了源码公式、
18 项证明、执行快照及原始日志。七项新 Lean 检查包含构建、三份空日志直接检查、
18 项公理审计、四项严格负控和与前基线的联合构建；仅使用允许的三项公理。
四个预定错误替代分别漏掉 truth 导数、提前读取未来行、将均值当成求和，以及将全相等
有限 score 的 CE 当成零。最终恰四个 `unsolved goals` / `False`，没有辅助错误。
两次早期负控仅修有限和归约助手，四个命题逐字未变，原执行证据保留。

[既有源码检查](../assets/lean_loss_20261018/existing_checks_01.json)实际通过九项梯度、
温度、前缀权重和 row/column 测试，源码和测试身份在执行前后相同；没有运行拟合或训练。
有限测试是源码行为证据，分别记录于数学证明和实现认证之外。

本片的 prefix 链对应历史 count-neutral mean 分支。一般 sum-membership 分支只复用
有限 score 的 CE 导数，不被重新解释为 mean。全相等 score 的 `log C` 结论也不泛化为
所有部分或近似平局。源码要求正温度、非空 D/R、合法候选和有限值；Lean 的部分恒等式
在更宽的 total-division 域成立，不代表这些额外输入获准进入实际 API。
精确 uniform 权重为 `1/R`；源码允许权重总和在 `1e-9` 内，该容差不是精确归一化定理。
零先验导致的负无穷、原生 reshape/AD/IEEE、其余损失族与优化器、完整 V06.a/V06.b
及原 17 子目标仍各自保留边界和未完成义务。

## 源辅助风险、SupCon 与 MMD 组件

[联合验收](../assets/lean_network_preprocessing_20261018/network_risk_fold_acceptance_01.json)
中辅助损失部分新增 39 个定理、10 个严格错误替代。
[独立复核](../assets/lean_source_auxiliary_20261018/independent_review_01.json)核对 SourceObjective、
deep fixed-update CE 和实际采样调用：CE 保留每次抽样并使用 `r_i/p_i`，辅助项按首次
物理行去重。SupCon 同类且 domain/person 都不同才是正例，其他同类不自动当作负例；
无有效 anchor 的分支与 active 风险分母明确。

MMD 采用实际 active cells 和 off-diagonal 归约，无偏估计量可为负；两个 API 的 median
带宽规则不同，detach 带宽只支持明确的局部梯度结论。独立 standalone AS-MMD API 在
`pos_weight=0` 且全正标签时返回 NaN；真实 adapter 的训练双类 gate 排除该具体见证，
不能将它报告为当前训练入口故障，也不能宣称所有 API 输入必有限。

六项作者检查、公理和严格反例保留原 v4 源码及 215/230 保护成员身份；八份相关源码
与 v5 相同。十项 CPU 证据分别为八项实际源码、一个 Torch 原语与一个纯代数控制，
未进行 fit、优化器更新或 GPU 训练。完整 V06.a/V06.b 与模型链式导数仍未由本片关闭。
