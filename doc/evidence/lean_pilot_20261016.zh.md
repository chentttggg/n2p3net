# Lean 自动形式化试验：协方差、候选证据与时间支持

日期：2026-10-16。角色：选定数学规格的形式化与软件行为诊断。

## 结果与范围

从当前源码自动提取并完成 14 个 Lean 定理，其中 2 个是块矩阵辅助引理。
完成构建、另起 Lean 进程重新检查本工程证明、逐定理公理审查，
以及两条故意错误证明的拒绝检查。全部通过；证明不含未完成占位。
公理依赖只包含 `propext`、`Classical.choice` 和 `Quot.sound`。

源码位于 [N2P3Pilot.lean](../../formal/lean/N2P3Pilot.lean)，
环境、定理清单和复现命令见 [工程入口](../../formal/lean/README.md)。
Lean 固定为 4.24.0，Mathlib 固定为 `f897ebcf72cd16f89ab4577d0c826cd14afaafc7`；
完整依赖由 `lake-manifest.json` 约束。没有更改生产算法、模型或原始数据。

| 源码表达式 | 本次形式化结论 | 前提及覆盖边界 |
|---|---|---|
| `JointNoiseModel.project` 的 `[A B] Σ [A B]ᵀ` | 展开保留 `AΓAᵀ`、`ACBᵀ`、`BCᵀAᵀ`、`BΩBᵀ` 四项 | 有限实矩阵代数；没有形式化随机变量及其二阶矩 |
| 固定算子传播 | 精确 PSD 输入经过任意固定线性算子仍为 PSD | 不推出 PD；给出非零秩一投影破坏 PD 的形式化反例 |
| `(cov+cov.T)/2` | 对称实矩阵保持原值 | 不包含浮点加法和舍入误差 |
| `membership_evidence(..., aggregation="sum")` | 未观测值不影响得分；标量 offset 减去 offset×有效 membership 计数 | 覆盖实数 sum 规格；不覆盖 legacy mean 和 NaN 的形式语义 |
| 候选偏置与排序 | 等有效计数时两候选得分差保持不变；不等计数允许严格反转 | 等计数是本次定理的充分条件；没有对任意缺失模式作无条件排名保证 |
| `binary_time_split` 与半开区间 | accepted test 不属于校准前缀，校准 epoch 与 test 支持分离，严格重叠谓词等价 | 接受 max-availability 上界及选行谓词；未形式化 NumPy max/索引构造/浮点时间，不推出 IIR 支持独立 |

这些定理证明选定实数规格。当前 Python/NumPy/SciPy/PyTorch 实现与这些规格之间的
完整 refinement、IEEE 754 误差界和真实调用链授权仍是独立证明任务。
使用官方依赖缓存；未以 trust=0 重新检查全部导入库。

## 独立行为检查与实际边界

项目 venv 下运行了 7 组对应的 Python 行为探针：

- 联合噪声取完全相关的 raw/state，各自方差约 10，实际传播方差约 40；
  去掉交叉项得到约 20。32 个算子实例的四项展开最大绝对差为 `2.842170943040401e-14`。
- 候选有效计数为 2 和 1，每条 evidence 为 1：offset=0 时得分 `[2,1]`，
  offset=2 时得分 `[-2,-1]`，严格排名反转。
- 不可用位置替换为 NaN 后，NumPy 与 Torch 的现有 sum 内核均保持得分；
  等计数实例在四个 offset 下保持两候选得分差。
- 495 组实际预算组合通过校准/test 行隔离、epoch 支持分离和 test/purged 分区检查。
  探针使用可由 float64 精确表示的二进有理数时间，不能推导任意浮点时间正确性。
- `validate_covariance(diag([1,-5e-11]))` 被现有相对容差门禁接受。
  该输入并非精确 PSD，说明数值门禁与数学前提之间存在可复现差距。
  后续应为此定义近似 PSD 与传播误差界，而不能把精确 PSD 定理直接迁移为所有
  已准入矩阵的保证。本试验未更改这一数值策略。

上述行为检查是有限软件证据；Lean 的一般定理与它们分别验收。
额外运行的 43 项已有测试全部通过：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/transfer/test_noise_model.py tests/models/test_candidate_evidence.py tests/transfer/test_calibration_inner_split.py tests/transfer/test_calibration_budgets.py -q
```

两条错误证明分别尝试认可“奇异投影后仍 PD”和错误的偏置后排序。
验证器要求它们在成功导入后留下 `⊢ False` 的未解决证明目标；路径、依赖或导入失败不算通过。

## 对预算的更新

本组已经证明：对有成熟 Mathlib 基础的有限维代数与时间/集合合同，本机即可自动完成
命题提取、反例、证明和审查。无需 GPU；本次内存峰值也没有要求升级机器。
本次成功不能线性外推到尚需新建数学基础的滤波递推、条件高斯推导、训练收敛或
浮点求解器正确性。下一组宜在真实依赖图上选择有限 SOS 状态递推与分解，或
连续候选低秩/完整高斯评分等价性，并单独记录缺失引理及开发时间。
