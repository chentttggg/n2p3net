# 算子 Phase 4：软边界、灵活先验、空间权重与成熟 ERP 混合

## 边界软约束

MSE 是均方误差：把每个预测误差平方后取平均。它对少数很大的错误特别敏感，因此适合衡量边界修正是否整体接近长上下文参考，但它不关心被修掉的部分是不是有用 ERP。

本轮把 `K U_ERP=0` 的硬约束改为预声明 penalty 网格 `0、1e-4、1e-3、1e-2、0.1、1、10、100、1e4`，同时报告差值 MSE、ERP 注入误差、白噪声能量倍率和约束残差。结果显示：

- 距边界 0 秒时，无约束 MSE 可降约81%，但 ERP误差约10%；penalty增大可把ERP误差降到约4%，代价是MSE改善降到约20%–35%。这里没有同时“大幅降MSE且只增加一点ERP误差”的稳定区域。
- 距边界 2 秒时，penalty约1–10可把MSE改善保持在约43%–55%，ERP误差降到约2%–3%，存在实用的Pareto区域。
- 距边界 8 秒时，penalty约1–100能保持约45%–47% MSE改善，ERP误差约0.4%–0.7%。

因此约束参数确实可以调出折中，但折中依赖距边界；不能设置一个全局数字后声称普遍安全。当前最合理的后续形式是把边界距离、可观测 context 和 ERP 保真约束一起作为显式状态，不能只按 MSE 选 penalty。

## 统一候选评分

Phase 4 使用相同八人、每人六个 selection 留一组的开发设计。参数网格和混合权重在评分前固定，held selection 不参与选择。比较了 raw AR8 的灵活 ridge 混合、Pz 固定/训练估计空间权重、Toeplitz ERP、xDAWN ERP，以及等权概率混合。

| 路线 | hit | NLL |
|---|---:|---:|
| raw AR8 单一 `lambda=1` | 0.479 | 2.961 |
| raw AR8 灵活先验等权混合 | 0.542 | 2.212 |
| Pz 固定空间 precision 权重 | 0.396 | 3.013 |
| 训练组 d-prime 空间权重 | 0.417 | 2.899 |
| Toeplitz | 0.771 | 2.163 |
| raw AR8 + Toeplitz 等权混合 | 0.771 | 1.339 |
| raw AR8 + Toeplitz + xDAWN 等权混合 | **0.771** | **1.069** |

这个结果给出了目前最有希望的开发候选：

\[
p(q\mid Y)=rac{1}{3}p_{raw\ AR8}(q)+rac{1}{3}p_{Toeplitz}(q)+rac{1}{3}p_{xDAWN}(q).
\]

它不是简单把 `F` 乘到 `D` 上，而是让三个模型分别承担不同任务：raw AR8保留连续时间和边界支持，Toeplitz表达时间协方差，xDAWN提取空间 ERP 方向。等权是预声明的稳健混合，不是根据 held 成绩选权重。

## Pz 权重的结论

Pz 在 P300 中常有较强信号，但“信号重要”不等于“把 Pz 的残差 precision 乘大”。本轮固定 Pz 权重和训练 d-prime 权重都使命中下降，说明简单通道加权改变了噪声模型，却没有正确表达 ERP 空间结构。Pz 信息更适合进入 xDAWN/ERP 空间原型或一个训练内估计的空间先验；不应直接手工放大残差似然。

## 灵活先验的结论

固定 ridge 过强会把时间噪声尺度误当作 ERP 先验尺度。等权 lambda mixture 比单一 raw AR8 改善 NLL，但仍弱于成熟 ERP 的命中。它适合保留为概率稳健性研究臂，不能直接成为默认正则。

当前下一步应在独立公共数据或新的合法 participant 上验证三模型混合，并同时保留单模型、Toeplitz、xDAWN 和 waveform LDA 对照。这个开发结果仍不能升级为十二库迁移或成人设备结论。
