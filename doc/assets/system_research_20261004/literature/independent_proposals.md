# Independent proposal register (before external retrieval)

Recorded 2026-10-04 Asia/Shanghai. AI-assisted hypotheses; no efficacy claim.

1. **Finite-support nuisance regression**. Replace a requirement to reproduce infinite-context 0.1 Hz filtering with explicit within-authority regression of line components and a cautiously regularized drift basis. Use regression baseline covariates, not mandatory subtraction with coefficient one. Prediction: pure-line edge ramps fall while source-held-out ERP contrast remains. Counterexample: a real ERP component lies inside the removed nuisance space and is erased.
2. **Continuous candidate-conditioned generative inference**. Fit class ERP kernels and noise on labeled calibration, then score an unknown decision by constructing each candidate's known physical flash-membership design and comparing the whole continuous segment likelihood after integrating nuisance. This uses no hidden test labels. Prediction: jointly modeled overlap matters most when stimulus onset interval is short and late ERP response informative. Counterexample: design columns are collinear, response changes with repetition, or target/non-target kernels fail superposition.
3. **Structured covariance classifier as serious comparator**. Per-target shrinkage time-domain LDA with block-Toeplitz or separable covariance; optional source-informed covariance shrinkage, not frozen source means. Geometry is target-native and missing channels remain explicit. Prediction: K-small stability and auditable margin improve over unrestricted fine-tuning, but performance is unproven. Counterexample: covariance is strongly time-varying or source covariance has incompatible reference/montage.
4. **Boundary uncertainty marginalized in decision space**. Represent finite-segment state ambiguity as low-rank output modes U, then add U Gamma U^T to feature noise covariance or constrain a classifier to be insensitive to these modes. Do not pretend to recover unknowable outside-support EEG. Prediction: fewer edge-driven high-confidence errors; test with ERP injected in U as mandatory failure mode. Counterexample: target ERP contrast itself belongs to span(U), making invariance destroy signal.
